# Rule-Based Chatbot

A simple conversational chatbot built using Python and rule-based logic.

## About the Project

This project is a rule-based chatbot that interacts with users through the command line.

It identifies specific keywords and user inputs and provides predefined responses based on programmed rules.

## Features

- Greets the user
- Responds to common conversations
- Provides help when requested
- Displays the current date and time
- Handles unknown inputs
- Allows the user to exit the conversation

## How It Works

The chatbot follows a simple logic-based approach:

1. The user enters a message.
2. The chatbot checks the input for specific keywords or commands.
3. The input is matched with predefined rules.
4. The chatbot provides the corresponding response.

## Technologies Used

- Python
- Conditional Statements
- Functions
- String Processing
- Rule-Based Logic
